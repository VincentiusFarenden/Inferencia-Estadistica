# Inferencia-Estadistica

Repositorio de ejercicios, laboratorios y material de apoyo para el ramo **MAT4152 / MAT3131 — Inferencia Estadística** (DuocUC). Incluye notebooks de Jupyter, formulario de referencia rápida y datasets en Excel.

---

## Contenido

| Archivo | Descripción |
|---|---|
| `FORMULARIO ESTADISTICA DESCRIPTIVA.ipynb` | Formulario de referencia con snippets listos para usar en Python |
| `Laboratorio_N_MAT4152.ipynb` | Enunciados de laboratorios prácticos |
| `Soluciones_Laboratorio_N_MAT4152.ipynb` | Soluciones de cada laboratorio |
| `MAT3131_Formulario_EA1.ipynb` | Formulario para evaluación alternativa MAT3131 |
| `G*_*.xlsx` | Datasets en Excel utilizados en los ejercicios |

---

## Requisitos

- Python **3.8 o superior**
- Jupyter Notebook, **Google Colab** o **VS Code** (con la extensión Jupyter)

---

## Librerías utilizadas

| Librería | Uso |
|---|---|
| `numpy` | Operaciones numéricas y generación de muestras aleatorias |
| `pandas` | Carga y manipulación de DataFrames desde Excel o CSV |
| `matplotlib` | Visualización de datos e histogramas |
| `scipy.stats` | Distribuciones estadísticas, intervalos de confianza, p-valores |
| `scikit-learn` | Cálculo de R² para regresión |
| `statsmodels` | Modelos estadísticos avanzados |
| `seaborn` | Visualizaciones estadísticas |
| `openpyxl` | Lectura de archivos `.xlsx` con pandas |

---

## Temas cubiertos

- Medidas de tendencia central y dispersión
- Coeficiente de asimetría y curtosis
- Distribución normal y cálculo de probabilidades
- Muestreo aleatorio y distribución de medias muestrales
- Intervalos de confianza para la media (t-Student y normal)
- Intervalos de confianza para la proporción
- Test de hipótesis para la media, proporción y diferencia de medias/proporciones
- Criterios de decisión: p-valor y valor crítico
